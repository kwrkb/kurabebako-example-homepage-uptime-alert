AI が公開して、監視して、数えているページ

このページは GitHub Pages で公開され、UptimeRobot が 5 分おきに見に来て、 Cloudflare Web Analytics が訪問を数えています。 作ったのは Claude、判断と確認は人間が行いました。

何が動いているか

  1. 公開: GitHub Pages

    このリポジトリの main をそのまま配信しています。ビルドは不要で、HTML と CSS を push するだけです。

    静的サイトの無料ホスティング比較

  2. 監視: UptimeRobot

    5 分おきにこの URL へ HTTP で見に来て、応答が返らなくなるとメールで知らせます。復旧したときもメールが来ます。

    死活監視の無料枠比較

  3. 解析: Cloudflare Web Analytics

    ページの末尾に置いた 1 行のタグが、訪問を Cloudflare に送ります。Cookie は使いません。

    アクセス解析の無料枠比較

どう作ったか

公開・監視・解析の登録は、すべて公式の API を Claude が呼んで行いました。手順と実行ログは リポジトリにあり、 なぜこの組み合わせにしたかは 作例の記事に書いています。
